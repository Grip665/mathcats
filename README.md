# Math Cats

A 2nd grade math adventure game — single self-contained HTML file.

Built for Ayva. Runs offline once loaded: worlds, yarn-pop, memory match and the Kitty Closet.
Progress is stored in the browser's localStorage on the device the game is played on.

## Play

Open the GitHub Pages URL, then on iPad: Safari → Share → Add to Home Screen.

```
https://grip665.github.io/mathcats/
```

## Notes

- One file: `index.html`. No build step, no dependencies beyond a Google Fonts link.
- If the network is unavailable the font falls back to Trebuchet MS; everything else still works.
- Clearing Safari website data resets the child's progress.
